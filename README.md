# Ucell · Инициатива роста ARPU архивной базы

Продуктовая инициатива по увеличению ARPU абонентов на архивных тарифах Ucell (Узбекистан):
анализ, международные бенчмарки, портфель инициатив (EASY / HARD), финансовая модель с Монте-Карло,
CJM, roadmap, data-driven дизайн и материалы для защиты перед руководством.

> 🟨 **Этап, который выполняете вы:** анализ внутренних данных — [docs/09_data_request_for_analysts.md](docs/09_data_request_for_analysts.md).
> Там полный список данных для аналитиков (D1–D16), пошаговый анализ и куда подставить результаты.

## Главное за 30 секунд

- Когорта: ~3,52 млн активных абонентов на архивных ТП, ARPU ~18 500 сум (гипотеза до данных).
- Портфель из 11 рекомендуемых инициатив + 1 опция; 1 идея отклонена моделью (B4).
- С поправкой на риск: **ARPU когорты +11,5% (P10–P90: +6,1…+16,9%)** за 24 мес., выручка **+36,7 млрд сум в Y1 / +64,6 млрд в Y2**,
  run-rate ≈ **$5,1 млн/год**, **P(≥ +10%) = 61%** (75% с опцией A8).
- Лидеры: **A2** точечная индексация (шанс 80%), **A1** Upgrade к 30-летию Ucell (92%), **B3** sunset (60%), **B1** AI NBO (64%).

## Модель

| Файл | Назначение |
|---|---|
| `model/assumptions.py` | Все допущения (гипотезы помечены `HYPOTHESIS`) и диапазоны параметров инициатив |
| `model/arpu_model.py` | Монте-Карло (20 000 прогонов × 24 мес.), шансы успеха, портфели, tornado, размеры A/B |
| `model/output/results.md` / `.json` | Результаты последнего прогона |
| `model/build_excel.py` | Генерация Excel |
| `model/Ucell_Archive_ARPU_Model.xlsx` | Калькулятор с живыми формулами: Inputs → Initiatives → Monthly (24 мес.) → Portfolio (+график), AB_Calculator, MC_Results |

```bash
pip install -r model/requirements.txt
python model/arpu_model.py     # пересчитать вероятности → model/output/results.md
python model/build_excel.py    # пересобрать Excel
```

Excel-движок повторяет детерминированный прогон Python один в один (проверено: расхождение < 1e-10 млрд сум).

## Определение метрики

ARPU считается по **когорте** абонентов, находившихся на архивных ТП на дату T0; мигрировавшие на актуальные ТП
остаются в когорте. Рядом всегда показываются выручка когорты и отток (ARPU может расти и от ухода низкодоходных абонентов).
