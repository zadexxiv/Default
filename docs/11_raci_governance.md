## 3. Управление программой

- **Steering Committee** (CCO — председатель, CFO, CTO, Legal, PM): раз в месяц + на каждом гейте G0–G5.
- **Решения по цене** (A2, A8, B3) принимает только SteerCo с визой Legal/GR.
- **Бюджет:** выделяется поэтапно — EASY сразу; B1 после RFP; B2/B5 только после пилотов; B3 после G3.
- **Отчётность:** ежемесячная страница «модель vs факт» (P50-прогноз vs инкрементальная выручка на holdout).
