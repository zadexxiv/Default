Без разработки сам тест стоит ~1,7 млрд сум (~23 тыс. сум на участника). Призовые фонды MVP — 30% от масштаба:
меньше нельзя, призы перестанут быть привлекательными. Поэтому результаты MVP по вовлечённости немного
оптимистичны, это учитывается при решении о масштабе.

**Вклад Loyalty** (маржа 85% от доп. выручки + Pass за вычетом ценности + партнёры − затраты):

| Показатель | P50 | Диапазон P10…P90 / вероятность |
|---|---|---|
| Вклад за 24 мес. | −9,5 млрд | −15,2 … −3,1 |
| Вклад за 36 мес. | **+12,4 млрд** | −3,2 … +30,7; P(> 0) = 84% |
| Месячный вклад на M24 | +0,87 млрд | P(> 0) = 97% |

**Чувствительность вклада Loyalty за 36 мес.** Базовый план — 10,4 млрд.

| Параметр | При минимуме | При максимуме |
|---|---|---|
| Доп. переходы на ТП ≥ 60 тыс. (0,15–0,8% в мес.) | −2,1 | +30,0 |
| Снижение оттока участников (8–25%) | −1,8 | +27,5 |
| Рост выручки от оплат вовремя (0,5–2,5%) | −3,1 | +23,6 |
| Доля вступивших из MAU (35–60%) | −2,3 | +18,6 |
| Себестоимость погашения монет (0,45–0,60) | +12,8 | +6,9 |

**Вывод для руководства.** Программа лояльности — инвестиция в удержание с окупаемостью ~2,5 года, а не быстрый
рычаг ARPU. Поэтому:
1. сначала MVP за ~$290 тыс.;
2. масштаб — только если MVP подтвердит H1–H3.
