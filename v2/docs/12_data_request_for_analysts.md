## 3. Ваш анализ: шаги

| Шаг | Что сделать | Источник | Результат → куда подставить |
|---|---|---|---|
| T1 | Размер и ARPU когорты | D1, D2 | Excel `Inputs!C5:C9`; `BASE` в `assumptions_v2.py` |
| T2 | **Неэффективные линейки для I1:** по каждому архивному семейству — абонентов, ARPU, использование пакета, затраты сопровождения, ближайший актуальный ТП и разница в цене (цель +10–15%) | D1, D3, D10 | Список линеек + `eligible_share`, `base_fee_gross`, `price_up_pct` (I1) |
| T3 | **Когорта для I2:** линейки с использованием пакета ≥ 60% и недоплатой ≥ 4 тыс. | D1, D3 | `eligible_share`, `price_up_gross` (I2) |
| T4 | **Эластичность** по волне 03.02.2026 (difference-in-differences, без соцгруппы) | D7 | `churn_incr`, `downgrade`, `downgrade_delta` (I1, I2) |
| T5 | Исчерпание пакета и самостоятельные докупки; роуминг-сегмент | D3, D5, D9 | I3a / I3b: `eligible_share`, `cannibal` |
| T6 | **Полосы АП** для всей базы, пользователей приложения и архивных | L1, L2 | `BANDS` → лист `Loyalty_Inputs` (жёлтые ячейки) → пересчёт листа `Thresholds` |

| T8 | Базовые переходы между ТП и отток пользователей приложения | L4, L6 | `upgrade_rate_m` (база), `member_churn_base` |
| T9 | Себестоимость и закупочные цены призов | L8, закупки | Лист `Prizes` (жёлтые цены), `Daily_Drops` |

## 4. Шаблоны SQL

```sql
-- L2: распределение по полосам АП (все / пользователи приложения / архивные)
SELECT CASE WHEN t.monthly_fee_gross < 30000 THEN 'lt30'
            WHEN t.monthly_fee_gross < 60000 THEN '30_59'
            WHEN t.monthly_fee_gross < 80000 THEN '60_79' ELSE 'ge80' END AS band,
       COUNT(*)                                                  AS subs,
       SUM(CASE WHEN a.mau_flag = 1 THEN 1 ELSE 0 END)           AS app_mau,
       SUM(CASE WHEN t.status = 'archive' THEN 1 ELSE 0 END)     AS archive_subs,
       AVG(r.revenue_net)                                        AS arpu
FROM dwh.subscriber_snapshot s
JOIN dwh.tariff_catalog t ON t.tariff_code = s.tariff_code
LEFT JOIN dwh.app_activity_monthly a ON a.sub_hash = s.sub_hash AND a.month = DATE '2026-10-01'
LEFT JOIN dwh.revenue_monthly r     ON r.sub_hash = s.sub_hash AND r.month = DATE '2026-10-01'
WHERE s.snapshot_date = DATE '2026-11-01' AND s.active_30d = 1
GROUP BY 1;

-- L5: breakage и микс погашения кэшбэка акции «+%»
SELECT DATE_TRUNC('month', e.earned_at) AS m,
       SUM(e.amount)                                                     AS earned,
       SUM(CASE WHEN x.spent_at IS NOT NULL THEN x.amount ELSE 0 END)    AS spent,
       SUM(CASE WHEN x.spend_type = 'package' THEN x.amount ELSE 0 END)  AS spent_packages,
       SUM(CASE WHEN x.spend_type = 'bill'    THEN x.amount ELSE 0 END)  AS spent_bill
FROM dwh.cashback_earn e
LEFT JOIN dwh.cashback_spend x ON x.earn_id = e.earn_id
GROUP BY 1;

-- L6: матрица переходов между полосами АП
SELECT f.band AS band_from, t.band AS band_to, COUNT(*) AS moves
FROM dwh.tariff_changes c
JOIN dim_band f ON c.fee_from BETWEEN f.lo AND f.hi
JOIN dim_band t ON c.fee_to   BETWEEN t.lo AND t.hi
WHERE c.changed_at BETWEEN DATE '2025-11-01' AND DATE '2026-10-31'
GROUP BY 1, 2;
```
